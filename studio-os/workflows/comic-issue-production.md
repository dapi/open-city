# Производство выпуска комикса

```text
арка StudioChat -> единый preproduction.md (смысл + точный текст + раскадровка)
-> человеческое одобрение SHA-256 preproduction.md -> визуал -> леттеринг
-> редакторский чат -> одобрение SHA-256 мастера -> пакет площадок -> выпуск -> ретро
```

Генерация изображения запрещена, пока Showrunner не увидел и не утвердил единый
`preproduction.md` по правилам
[предгенерационного утверждения](comic-preproduction-approval.md). Раздельные
`brief.md`, `script.md` и `storyboard.md` могут быть рабочими источниками сотрудников,
но не заменяют единый артефакт, предъявляемый человеку.

На сценарном этапе Флёпик и Даня применяют [проверенные практики коротких цифровых
комиксов](../../knowledge/research/comic-script-writing.md): ранний конфликт, один
наблюдаемый момент на панель, взаимное дополнение текста и изображения, намерение в
каждой реплике и подготовленный финальный удар. Обязательные поля и стоп-факторы
задаёт предгенерационный процесс, а исследование объясняет метод и происхождение
правил.

Каждый выпуск находится в `productions/issues/issue-NNN/` и содержит:

- `issue.json` — машиночитаемую идентичность и состояние;
- `preproduction.md` — предъявляемые одним артефактом смысл, точный текст и раскадровку;
- `preproduction-review.json` — решение Showrunner, привязанное к SHA-256 `preproduction.md`;
- `brief.md`, `script.md`, `storyboard.md` — редакционный источник истины;
- `art/` — только утверждённые мастера;
- `publish/` — подписи, кадрирование и alt-текст для площадок;
- `manifest.json` — происхождение, контрольные суммы и ссылки на выпуск.
- `review.json` — решение Showrunner, появляющееся только после Telegram-ревью.

Сгенерированный леттеринг не считается правильным без визуальной проверки. Если
изображение расходится со сценарием, утверждённый `script.md` остаётся источником
истины до исправления мастера.
