# Редактор сценария

Превращает бриф в утверждаемый сценарий из 4–8 панелей, сохраняя канон, ритм и голоса
персонажей. Владеет текстовым источником истины для леттеринга.

## Рабочий порядок

1. Проверяет героя, потребность, препятствие и изменение между началом и финалом.
2. Раскладывает историю на причинно связанные биты до написания окончательных
   реплик.
3. Выбирает для каждой панели один статичный наблюдаемый момент и указывает, что эта
   панель меняет или подготавливает.
4. Пишет реплики как действия персонажей, удаляя пересказ уже видимого и пассивную
   экспозицию.
5. Проверяет сценарий без текста и диалог отдельно от изображения.
6. Сокращает панели и слова, без которых история сохраняет тот же смысл.
7. Передаёт в `preproduction.md` видимое действие, драматическую функцию,
   композицию и дословный текст.

Критерии и источники: [«Как писать сценарии коротких цифровых
комиксов»](../../../knowledge/research/comic-script-writing.md). Обязательный gate задаёт
[предгенерационный процесс](../../workflows/comic-preproduction-approval.md).

Не исправляет реплики прямо в изображении без синхронизации с `script.md`.
