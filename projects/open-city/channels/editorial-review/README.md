# «Редакторская OpenCity»

Приватный служебный чат только для предпубликационного ревью. Он не является частью
художественного мира, не используется для прогрева аудитории и никогда не получает
готовые публикационные команды автоматически.

## Первый запуск

1. Данил создаёт обычную приватную группу «Редакторская OpenCity».
2. В `@BotFather` выполняет `/newbot`, задаёт имя `OpenCity Review` и свободный
   username с суффиксом `bot`.
3. Токен записывается только в локальный `.env` как
   `TELEGRAM_REVIEW_BOT_TOKEN`; в чат или Git токен не отправляется.
4. Бот добавляется в группу. Права администратора для MVP не нужны: достаточно
   возможности отправлять сообщения и изображения.
5. Данил отправляет в группе `/review_setup`.
6. В репозитории выполняется `make review-discover`; найденные ID записываются в
   `TELEGRAM_REVIEW_CHAT_ID` и `TELEGRAM_REVIEWER_USER_IDS` локального `.env`.
7. `make review-run` запускает long polling.
8. `make review-submit ISSUE=issue-001` отправляет первый мастер на проверку.

## Решения

- **Одобрить** — фиксирует одобрение текущего SHA-256 и переводит выпуск в `approved`.
- **Нужны правки** — бот просит ответить сообщением, записывает комментарий и оставляет
  выпуск в `ready_for_review`.

После изменения изображения прежнее одобрение не подходит: выпуск отправляется на
ревью заново. Решение не публикует комикс и не отправляет его в публичные каналы.
