# Портреты персонажей

Портреты в этой папке — управляемые ассеты картотеки сайта. Краткая режиссура образа
хранится в `characters.json` и показывается в публичном профиле; полные промпты,
источники, размеры и контрольные суммы записаны в [`manifest.json`](manifest.json).

| Персонаж | Файл | Краткая режиссура |
|---|---|---|
| Даня | [`danya-portrait-v1.png`](danya-portrait-v1.png) | Усталый прямой взгляд, тёмное худи и человек, который всё ещё спрашивает «зачем» |
| Флёпик | [`flepik-portrait-v1.png`](flepik-portrait-v1.png) | Круглая cyan-голова, две петли-антенны и доброжелательная буквальность системы |
| Бабка Марина | [`marina-portrait-v1.png`](marina-portrait-v1.png) | Спокойный прямой взгляд, тёмный платок и человеческая мера без карикатуры |
| Мэр-чатбот | [`mayor-chatbot-portrait-v1.png`](mayor-chatbot-portrait-v1.png) | Прямоугольная magenta-голова-экран, строгий костюм и уверенность избранного алгоритма |
| Курьер-дрон Гриша | [`grisha-portrait-v1.png`](grisha-portrait-v1.png) | Парящий teal-корпус, оранжевая грузовая кассета и усталый взгляд философа |
| NEYRA | [`neyra-portrait-v1.png`](neyra-portrait-v1.png) | Прямой взгляд, узнаваемый magenta-силуэт и контролируемая публичная искренность |
| Макс Хайпштейн | [`max-hypestein-portrait-v1.png`](max-hypestein-portrait-v1.png) | Прямой взгляд, узнаваемый orange-силуэт и опасно убедительная энергия продюсера внимания |

Все семь портретов созданы по действующей визуальной системе с утверждёнными
выпусками 001 и 004 в качестве стилевых источников. Они не являются реставрациями
архивных U-P2-портретов: исходные варианты сохраняются отдельно для сравнения.
