# Личное редакторское ревью OpenCity

На первом этапе ревью проходит в личном диалоге Данила с ботом. Отдельная группа не
нужна. Этот диалог не является частью художественного мира, не используется для
прогрева аудитории и не запускает публикацию автоматически.

## Первый запуск

1. В `@BotFather` Данил выполняет `/newbot`, задаёт имя `OpenCity Review` и свободный
   username с суффиксом `bot`.
2. Токен записывается только в локальный `.env` как
   `TELEGRAM_REVIEW_BOT_TOKEN`; в чат или Git токен не отправляется.
3. Данил открывает личный диалог с ботом и отправляет `/start` или любое сообщение.
4. `make review-configure-private` находит последнее личное сообщение и записывает
   chat ID и user ID только в локальный `.env`, не показывая их в выводе.
5. `make review-run` запускает long polling.
6. `make review-submit ISSUE=issue-001` отправляет первый мастер на проверку.

Если позже появится редакторская группа, её идентификаторы можно найти командой
`make review-discover` и явно записать в `.env`.

## Решения

- **Одобрить** — фиксирует одобрение текущего SHA-256 и переводит выпуск в `approved`.
- **Нужны правки** — бот просит ответить сообщением, записывает комментарий и оставляет
  выпуск в `ready_for_review`.

После изменения изображения прежнее одобрение не подходит: выпуск отправляется на
ревью заново. Решение не публикует комикс и не отправляет его в публичные каналы.
