# «Город Нейросеть — комиксы» (`@opencity_studio`)

Это Telegram-площадка для готовых комиксов OpenCity. Здесь выходят два обязательных
выпуска в неделю и третий необязательный, если производственный буфер позволяет.
Переговоры студии и диалоги персонажей публикуются в StudioChat.

Семнадцать существующих постов остаются архивом развития визуального языка проекта.

## Предлагаемое описание Telegram

> Сатирические комиксы о городе, где жители избрали мэром нейросеть. Новые
> выпуски 2–3 раза в неделю. Закулисье студии: «Синхронизация — чат OpenCity Studio».
