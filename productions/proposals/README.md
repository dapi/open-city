# Предложения выпусков

Здесь хранятся пакеты выбора, в которых ещё нет утверждённого сценария. Эти файлы не
являются каноном и не разрешают генерацию изображения. После выбора один вариант переносится в
`productions/issues/issue-NNN/preproduction.md` и проходит штатное предгенерационное утверждение.

- [Нулевой выпуск](issue-000-options.md) — три варианта истории о выборах Мэра-чатбота.
