# Цифровые сотрудники OpenCity Studio

Это цифровые сотрудники, технически настроенные через механизм project agents Codex.
Они читают репозиторий в режиме `read-only`, обсуждают работу и возвращают
предложения ведущему сотруднику или человеку.

| Сотрудник | Когда обращаться |
|---|---|
| `flepik` | premise, сюжетный разворот, превращение ограничения в историю |
| `danya` | сценарий панелей, сокращение и точный леттеринг |
| `neyra` | раскадровка, визуальная система и ревью мастера |
| `marina` | понятность, подводки, alt-текст и адаптация площадок |
| `showrunner-guard` | сводная проверка перед решением Данила |

Можно написать Codex: «Поговори с Флёпиком об этой идее», «Попроси Даню
отредактировать сценарий» или «Собери креативный совет». Имена совпадают с персонами
StudioChat, но сотрудники выполняют производственные роли и ничего не публикуют.
