## 5. Сценарная самопроверка

- [ ] Конфликт начинается не позже первой трети выпуска либо задержка обоснована.
- [ ] В каждой панели только один наблюдаемый момент.
- [ ] Каждая панель меняет ситуацию или необходима для подготовки изменения.
- [ ] Реплики не пересказывают уже видимое.
- [ ] У каждой реплики есть намерение и возможное последствие.
- [ ] Без текста понятны действие, отношения и изменение ситуации.
- [ ] Без изображения различимы голоса персонажей и логика диалога.
