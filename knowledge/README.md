# Knowledge

- `sources/` — raw evidence and imported conversations.
- `research/` — interpreted research, still subject to promotion.
- `decisions/` — decisions that may become ADRs or canon changes.
- `provenance/` — source-to-canonical mappings and verification records.

Raw sources never override canonical project or studio documents automatically.
