# Color-Breath v1

Пакет утверждён Showrunner 2026-08-10 **в первом приближении**. Он включает одну
калибровочную страницу и шесть действующих модельных листов. Файлы можно использовать в
сценических пробах как изображения-источники.

Файл `05-mayor-chatbot-model-sheet-v2.png` сохранён как исторический источник и
не используется: ADR 0007 отменяет его телесную трактовку Нейро-мэра.

Модельный лист пока фиксирует эталонный профиль: силуэт, пропорции, лицо, одежду,
базовые выражения и локальные цвета персонажа. Он не задаёт единственный способ
рендера сцены. Color-Breath накладывает на профиль среду, освещение, фактуру и
локальный температурный контраст; допустимо тестировать разные визуальные версии
страницы, если сохраняются инварианты визуальной системы.

Пакет не считается финальным мастер-набором до проверки персонажей в нескольких
совместных сценах. Полные промпты сохранены в [`PROMPTS.md`](PROMPTS.md), размеры,
контрольные суммы и роли файлов — в [`manifest.json`](manifest.json).
