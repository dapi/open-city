# Новости OpenCity Studio

Канонический источник раздела `/news/` — [`news.json`](news.json). Здесь публикуются
материалы о внутреннем производственном процессе, принятых решениях, визуальных и
сценарных экспериментах. Сайт собирает страницы автоматически; HTML не редактируется
вручную.

Поле `telegram_announcement` хранит короткий анонс для Telegram. Наличие текста не
означает автоматическую отправку: публикация в канал требует отдельного явного
действия человека-оператора.
