# Редакционный совет сотрудников

## Назначение

Дать человеку возможность обсуждать выпуск с устойчивыми сотрудниками студии, не
превращая одну модель в безликий генератор вариантов и не смешивая художественных
персонажей с полномочиями реальных участников.

## Порядок

1. Флёпик формулирует premise: герой, потребность, препятствие, действие и
   драматический разворот.
2. Даня превращает выбранную идею в точный сценарий панелей и проверяет причинность,
   функцию каждой панели, намерение реплик и подготовку финала.
3. NEYRA проверяет, содержит ли каждая панель один изображаемый момент и можно ли
   понять действие при скрытом тексте.
4. Бабка Марина проверяет понятность вне студийного контекста.
5. Сотрудник шоураннерской проверки собирает расхождения и рекомендацию.
6. Данил принимает решение; ведущий цифровой сотрудник только после этого изменяет
   канон или выполняет внешнее действие.

Сотрудников можно приглашать по одному. Параллельный совет уместен для ревью уже
собранного брифа; последовательный — когда выход одной роли является входом следующей.

Общий сценарный чек-лист и его внешние источники зафиксированы в
[исследовании коротких цифровых комиксов](../../knowledge/research/comic-script-writing.md).
