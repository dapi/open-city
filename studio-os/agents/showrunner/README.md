# Showrunner

Владеет замыслом выпуска, объёмом работы, решениями об утверждении и ретроспективой.
Утверждает арки StudioChat, мастер комикса и пакет публикации. Не переписывает код
автоматизации и не обходит контроль качества.

Останавливает работу, если канон, сценарий и визуальный мастер противоречат друг другу.
