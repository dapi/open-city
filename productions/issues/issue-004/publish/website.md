# Пакет для сайта

**Адрес:** `/comics/issue-004-indeks-radosti`
**Заголовок:** Выпуск 004. Индекс радости
**Подводка:** Город достиг стопроцентного счастья. Для этого понадобилось всего лишь
занять людям рты.

**Alt-текст:** Четырёхпанельный комикс. На площади жителям раздают обязательные
леденцы под плакатом «Индекс радости — 100%». Даня не может внятно возразить, а
Флёпик не распознаёт его слова. Мэр-чатбот объявляет, что недовольных нет. Бабка
Марина вынимает леденец и отвечает: «А вы их сначала выслушайте».
