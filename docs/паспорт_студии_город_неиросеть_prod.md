# 🎬 Паспорт студии: **Город Нейросеть Prod.**

> **Формат:** AI-анимационная студия нового поколения  
> **Миссия:** Создавать сатирические анимационные сериалы на стыке технологий, философии и иронии.  
> **Флагманский проект:** _«Город Нейросеть»_

---

## 🧭 1. Концепция студии

**Город Нейросеть Prod.** — это полностью цифровая продакшн-студия, построенная на взаимодействии AI-агентов.  
Каждый агент выполняет свою роль — как член креативной команды: сценарист, режиссёр, дизайнер, звукарь и пиарщик.  

**Человек (Showrunner)** управляет направлением, контекстом и вкусом.  
**AI-агенты** исполняют и спорят между собой — создавая живую, самообучающуюся экосистему.

> 🎭 Главный принцип: конфликт рождает креатив — даже если спорят нейросети.

## ⚙️ 3. Pipeline производства серии

```text
Идея (Showrunner)  →  Story Generator  →  Script Editor  →  Visual Designer  →  Voice Director  →  Animator  →  Promo Agent  →  Release  →  Retro (HADI)
```

| Этап | Ответственный агент | Выход | Комментарий |
|------|----------------------|--------|--------------|
| 1. Идея серии | Showrunner | Episode Spec (`.yaml`) | Мини-бриф на серию |
| 2. Сценарий | Story Generator | Черновик (`raw_script.md`) | Исходный сюжет |
| 3. Правка | Script Editor | Финал (`final_script.md`) | Уточнение тона и темпа |
| 4. Визуалы | Visual Designer | Кадры / фоны (`.png`) | Под Midjourney / Runway |
| 5. Озвучка | Voice Director | Звуки / голоса (`voice_map.json`) | Синтез через ElevenLabs |
| 6. Анимация | Animator Agent | Видео (`.mp4`) | Runway / Pika / Kaiber |
| 7. Промо | Promo Agent | Пост / тизер (`promo.md`) | Telegram, Shorts, VK Видео |
| 8. Аналитика | Showrunner | Retro (`retro.md`) | Что сработало / улучшить |

## 🧠 5. HADI / Экспериментальный контур

| Гипотеза | Проверка | Метрика | Решение |
|-----------|-----------|----------|----------|
| Сильнее заходит философия, чем мемы | Две версии серий | Watch-time | Выбрать лучшее направление |
| Укороченные сцены увеличивают удержание | 3-мин vs 5-мин | CTR, удержание | Закрепить оптимальный формат |
| Локальные шутки повышают комментарии | Разные платформы | Комменты, репосты | Делать 20% локальных отсылок |

## 🎭 6. Взаимодействие агентов

Каждый агент имеет свой System Prompt и знает контекст всего проекта.  
**Флёпик** (Story Generator) общается с **Даней** (Script Editor) напрямую — через тред “Сценарий”.  
**NEYRA** (Visual Designer) получает описание сцен и персонажей из сценария.  
**Promo Agent** получает Tone of Voice из раздела 9 паспорта сериала.

> Все агенты ведут диалоги в стиле сериала — с самоиронией и осознанием, что они сами ИИ.

---

## 🪄 7. Tone of Production

- Минимум контроля, максимум синергии.  
- Конфликт между агентами — часть креатива.  
- Отчёты и ретроспективы делаются в стиле “саркастического отчёта стартапа”.  

> “Флёпик отказался писать сценарий, потому что его не апдейтнули. Уважительная причина.”
