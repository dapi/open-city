# Сайт «Города Нейросеть»

Сайт собирается из канонических производственных пакетов, поэтому заголовки,
описания, изображения и alt-тексты не дублируются вручную в веб-коде.

Это обязательное правило для всего сайта: репозиторий `open-city` является
источником истины, а HTML — только результатом сборки. Профили героев берутся из
`../canon/characters/characters.json`; любые исправления сначала вносятся туда.

## Локальный просмотр

```bash
make site-preview
make site-serve
```

Первая команда создаёт закрытый предпросмотр всех выпусков в `var/output/site`.
Вторая запускает локальный сервер на `http://127.0.0.1:4173`.

Публичная сборка `make site` включает только выпуски со статусом `published`.
Предпросмотр содержит `noindex` и заметную плашку, поэтому не является публикацией.

## Синхронизация картотеки с публичным репозиторием

```bash
make site-sync-characters
```

Команда создаёт публичную сборку без черновиков и обновляет только управляемые
файлы `characters/index.html` и `assets/styles.css` в соседнем репозитории
`opencitystudio.ru`. Ручные изменения фактов в этих файлах будут потеряны при
следующей синхронизации и потому запрещены.
