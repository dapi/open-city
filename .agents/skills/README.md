# Сценарные skills OpenCity

Репозиторные skills для сценарной разработки. Codex обнаруживает их в
`.agents/skills`; они дополняют роли и процессы студии, но не заменяют канон,
утверждение сценария или редакционные контракты.

## Установленный набор

Источник: [`jwynia/agent-skills`](https://github.com/jwynia/agent-skills), коммит
`e02ec7e226a6e4f8419fd3b88a1d8e472d421b32`, установлен 2026-08-09.

- `story-collaborator` — активная сценарная разработка и варианты сцен.
- `dialogue` — диагностика диалогов, голосов и подтекста.
- `scene-sequencing` — структура сцен и управление темпом.
- `joke-engineering` — диагностика и усиление юмора.

Вспомогательные скрипты установлены без изменений из upstream. Их эвристики
ориентированы преимущественно на английский язык, поэтому вывод для русских
сценариев нельзя использовать как автоматический критерий качества.

## Внешний референс

Периодически сверяться с
[`baoyu-comic`](https://www.skills.sh/jimliu/baoyu-skills/baoyu-comic) и брать оттуда
идеи для сториборда, компоновки панелей и организации производственных материалов.
Сам skill не установлен. Заимствованные приёмы должны быть адаптированы к формату
OpenCity и пройти действующие сценарные и визуальные проверки.
