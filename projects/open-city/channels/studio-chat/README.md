# «Синхронизация — чат OpenCity Studio»

StudioChat — публичный ролевой чат, где персонажи OpenCity Studio обсуждают реальные
творческие ограничения через художественную переписку. Повторяющаяся рубрика чата
называется «Синхронизация».

У чата три задачи:

1. прогревать аудиторию между выпусками комикса;
2. вводить конфликт, который станет следующим выпуском;
3. превращать процесс студии в часть мира OpenCity.

StudioChat не является службой поддержки, закрытым рабочим чатом или архивом готовых
работ. Комиксы публикуются в `@opencity_studio` и на сайте.
