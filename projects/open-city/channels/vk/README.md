# «Город Нейросеть — комиксы» во ВКонтакте

**Тип:** публичная страница.
**URL:** [`https://vk.ru/opencity_comics`](https://vk.ru/opencity_comics), ID сообщества `club240763284`.
**Роль:** нативные полные выпуски, обсуждение и короткие тизеры в VK Клипах.
**Telegram:** [`@opencity_studio`](https://t.me/opencity_studio) добавлен в ссылки
сообщества и назначен целью кнопки действия.
**Сайт:** адрес ещё не назначен; добавить после фиксации канонического домена.

## Правила

- Использовать тот же номер и название `issue-NNN`, что на сайте и в Telegram.
- Публиковать полный выпуск нативной фотокаруселью; ссылка на сайт дополняет, но
  не заменяет изображения.
- В описании указывать, что это сатирический AI-assisted комикс OpenCity Studio.
- Тизеры VK Клипов не считаются отдельными каноническими выпусками.
- Записывать URL поста в `manifest.json` сразу после публикации.
- Ничего не публиковать без явного утверждения человека-оператора.
