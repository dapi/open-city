# Knowledge Base DNA

Этот каталог — конституция базы знаний OpenCity Studio OS. Правила адаптированы из
[`dapi/memory-bank/memory-bank/dna`](https://github.com/dapi/memory-bank/tree/main/memory-bank/dna)
и уточнены для AI-first производства.

Читать в таком порядке:

1. [Принципы](principles.md) — SSoT, границы контекстов, progressive disclosure и
   отделение источников от канона.
2. [Governance](governance.md) — authority, canonical owners и dependency graph.
3. [Frontmatter](frontmatter.md) — минимальная машинно-читаемая схема документа.
4. [Lifecycle](lifecycle.md) — изменение, синхронизация и продвижение знаний.
5. [Cross-references](cross-references.md) — связи docs ↔ code ↔ production artifacts.

До завершения миграции правила обязательны для новых и изменяемых governance,
architecture и knowledge-документов. Legacy production-документы включаются постепенно.
