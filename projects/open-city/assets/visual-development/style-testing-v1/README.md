# Тестирование стиля v1

Пакет содержит редакционные примеры, опубликованные вместе со статьёй о выборе и
проверке визуального языка OpenCity. Это не новый мастер персонажей: изображения
показывают ход теста, обнаруженные расхождения и две допустимые тональности одной
системы — `Light Deadpan` и `Light Warm`.

Во всех сравнительных листах слева находится `Light Deadpan`, справа — `Light Warm`.
Экранный телесный Мэр в пакет не включён: актуальный канон показывает его только как
распределённое присутствие через синхронные городские интерфейсы.

Гриша показан с утверждённым бортовым идентификатором `CITY-005` на видимой грани
оранжевой грузовой кассеты.

Состав, размеры и контрольные суммы находятся в [`manifest.json`](manifest.json),
основные prompt-блоки — в [`PROMPTS.md`](PROMPTS.md).
