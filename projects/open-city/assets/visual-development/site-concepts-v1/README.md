# Концепты сайта v1

Пакет содержит четыре сравнительных макета главной страницы, созданных на общей
информационной архитектуре. Данил Письменный рассмотрел пакет 2026-08-10 и выбрал
**«Муниципальную операционную систему»** основным направлением сайта.

Статусы изображений:

1. `01-municipal-os-selected-v1.png` — утверждённое направление интерфейса.
2. `02-digital-city-hall-illustration-reference-v1.png` — не выбранный макет;
   иллюстрация внутри него сохранена как сильный визуальный референс.
3. `03-punk-bulletin-archive-v1.png` — архивный вариант без назначения в текущей
   реализации.
4. `04-city-map-page-candidate-v1.png` — кандидат для отдельной страницы карты
   города, но не утверждённый макет этой страницы.

Макеты фиксируют направление, а не готовый дизайн. Сгенерированные гербы, тексты,
персонажи и сюжетные детали не являются каноном и не переносятся в сайт без
редакторской и визуальной проверки. Полные промпты находятся в
[`PROMPTS.md`](PROMPTS.md), размеры, роли и контрольные суммы — в
[`manifest.json`](manifest.json).
